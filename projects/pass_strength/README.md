# Password Strength Analyzer

This simple command-line tool analyzes the strength of a given password and provides a score based on various factors such as length, character types, and common patterns.

## Building

```bash
mkdir build
cd build
cmake ..
make
```

## Running

```bash
./app <password>
```

## Example Usage

```bash
./app MyP@sswOrd123
```

This will output a strength score and a brief analysis of the password.
